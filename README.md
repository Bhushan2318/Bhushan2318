### Sanket: forecast-bust early warning for India
Sanket doesn't forecast the weather. It predicts when an existing forecast is about to be badly wrong,
for every one of India's 666 districts, Day 1–10, and explains each prediction with SHAP.

- Trained on 20 years of the NOAA GEFSv12 reforecast archive against ERA5
- XGBoost + SHAP, served on a free tier at $0 hosting
- Smart India Hackathon 2026, problem statement 26079
- Live: https://sanket-a0dd.onrender.com · Code: https://github.com/Bhushan2318/sih-main

**Stack:** Python · FastAPI · XGBoost · scikit-learn · SHAP · pandas/PyArrow · React + TypeScript · GitHub Actions
