### 🌦️ Featured: Sanket, forecast-bust early warning for India

<a href="https://sanket-a0dd.onrender.com">
  <img src="https://raw.githubusercontent.com/Bhushan2318/sih-main/main/docs/images/hero.png" width="100%" alt="Sanket dashboard"/>
</a>

Sanket doesn't make another weather forecast. It predicts **when an existing forecast is about to go badly wrong**, for every one of India's **666 districts, Day 1 to 10**, and explains each prediction with **SHAP**.

| | |
|---|---|
| 📡 **Data** | The 20-year NOAA GEFSv12 reforecast archive, verified against ERA5, pulled with HTTP range requests |
| 🗺️ **Geography** | Area-weighted district means from GADM 4.1 boundaries, with the same weight table on both sides of the label |
| 🤖 **Models** | XGBoost error regressors and a bust classifier, with SHAP attribution for every prediction |
| 🖥️ **Product** | FastAPI + React/TypeScript dashboard: confidence maps, ranked alerts, and a replay of real past busts |
| ⚙️ **Infra** | GitHub Actions trains and ships it; a free web tier serves it. Hosting cost: **$0** |
